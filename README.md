# Azqm

Приложение за Android за хранене, хранителни режими и гладуване — на български, работи и без интернет.

## Изтегляне

Най-новата версия: **[Releases → Azqm.apk](../../releases/latest)**

1. Отвори линка от телефона и изтегли `Azqm.apk`.
2. Отвори файла и натисни „Инсталирай“. Ако телефонът попита, разреши „Инсталиране на неизвестни приложения“ за браузъра или „Файлове“.
3. Новите версии се инсталират върху старата — данните се запазват.

## Възможности

- **Днес** — калории и макроси спрямо целта, вода, статус на поста, хранения (закуска/обяд/вечеря/междинно), предупреждения при прекомерен прием на натрий, захар и др.
- **Добави** — търсене в 1023 храни (и на латиница), „+“ добавя порция с едно докосване, количество с порции и бутони − / +, любими, последни, „Мои храни“, баркод (OpenFoodFacts), снимка (по избор, с личен API ключ за Gemini/OpenAI), ръчно въвеждане.
- **Анализ** — средни калории и макроси за 7/30/90 дни или всичко, дефицити и излишъци на 25 витамина, минерала и др., с подходящи храни и основни източници.
- **Прогрес** — тегло, BMI с анимирана фигура, графика.
- **Пост** — таймер 12:12 … 72 ч, етапи, история, електролити.
- **14 режима** — Кето, Диетата на Атанас Узунов, Нисковъглехидратна, Нискомазнинна, Балансирана, Средиземноморска, Зоната, DASH, Високопротеинова, Палео, Вегетарианска, Веганска, Карнивор, Лечебно гладуване.
- **Експорт** — Excel, CSV, резервно копие и възстановяване.
- **Изглед** — тъмна/светла тема, три размера на текста.

> Приложението дава ориентировъчна информация и не замества консултация с лекар или диетолог.

## За разработка

Expo SDK 57 · React Native · TypeScript · expo-router · expo-sqlite.

```bash
npm install
npx expo start            # dev сървър
npx tsc --noEmit          # проверка на типовете
npx expo lint
```

**APK** се сглобява автоматично от GitHub Actions (`.github/workflows/android.yml`) при всеки push в `main`. Таг `vX.Y.Z` публикува Release с `Azqm.apk`. Подписът е в secrets `AZQM_KEYSTORE_BASE64` и `AZQM_KEYSTORE_PASSWORD`.

**База храни** — съставя се от `data-src/foodmap/*.json` (български имена, порции, тагове) и данни от USDA FoodData Central (SR Legacy, публичен домейн):

```bash
npm run foods:fetch       # изтегля USDA данните в .usda/
npm run foods:build       # генерира src/data/foods.generated.ts
```
